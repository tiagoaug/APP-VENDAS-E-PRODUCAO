Política de Privacidade

Aplicativo: Vendas e Produção — última atualização: setembro de 2026

Esta política explica quais dados o aplicativo Vendas e Produção coleta, como são usados e armazenados, e quem é o responsável por eles.

Tiago Augusto de Lima, CPF 085.952.566-08, desenvolvedor e responsável individual pelo aplicativo Vendas e Produção.

Quais dados são coletados

O aplicativo é uma ferramenta de gestão comercial e de produção. Os dados abaixo são inseridos pelo próprio usuário durante o uso normal do app, para o funcionamento das suas próprias funcionalidades:

  • Conta de acesso: e-mail e senha (ou login com Google), usados apenas para autenticação.
  • Dados de negócio: vendas, orçamentos, compras, estoque, produção, financeiro, contas e transações cadastradas pelo usuário.
  • Contatos comerciais: clientes, fornecedores e colaboradores cadastrados pelo usuário (nome, telefone, endereço, e outros dados que o próprio usuário decidir registrar).
  • Fotos: imagens de produtos e materiais, tiradas ou selecionadas pelo usuário através da câmera ou galeria do aparelho.
  • Localização: usada apenas na função de roteirização de entregas, para calcular rotas — não é coletada em segundo plano nem fora dessa função.
  • Contatos do aparelho: acessados apenas se o usuário optar por importar um contato existente do celular como cliente ou fornecedor dentro do app.
  • Biometria do aparelho (digital/rosto): usada apenas para desbloquear o próprio aplicativo no aparelho do usuário — a biometria nunca sai do aparelho nem é enviada a nenhum servidor.
  • Notificações push: usadas para avisos do próprio app (ex: pedidos recebidos, lembretes).

Onde os dados ficam armazenados

Os dados são armazenados de forma segura na infraestrutura do Google Firebase (Google Cloud), isolados por conta — cada usuário só acessa os próprios dados. Não compartilhamos, vendemos ou alugamos os dados dos usuários a terceiros.

Compartilhamento de dados

Os dados não são compartilhados com terceiros, exceto quando estritamente necessário para o funcionamento do serviço (ex: os próprios servidores do Google Firebase, que armazenam e processam os dados em nome do usuário) ou quando exigido por lei.
